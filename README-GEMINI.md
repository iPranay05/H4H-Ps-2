# Gemini Market Predictor for EzFunds

## Overview

The Gemini Market Predictor is an AI-powered feature that uses Google's Gemini AI to predict whether markets will be bullish or bearish for various assets. This feature analyzes market data and trends to provide insights on potential market movements.

## Features

- **Market Trend Predictions**: Get AI-powered predictions on whether a stock or cryptocurrency will be bullish or bearish
- **Confidence Scores**: See how confident the AI is in its predictions
- **Technical Indicators**: View key technical indicators that influenced the prediction
- **Support and Resistance Levels**: Get estimated support and resistance levels for assets
- **Batch Analysis**: Analyze multiple assets at once

## Setup

### API Key Configuration

The Gemini Market Predictor uses Google's Generative AI API. The API key is configured in the following locations:

1. In the `config/api-keys.ts` file (for development)
2. As an environment variable `NEXT_PUBLIC_GEMINI_API_KEY` (for production)

### Accessing the Feature

You can access the Gemini Market Predictor in two ways:

1. From the dashboard, click on the "Try Market Predictor" button in the Gemini Market Predictor card
2. Navigate directly to `/dashboard/market-predictor`

## Usage

### Single Asset Prediction

1. Select an asset from the dropdown or choose "Custom Asset" to enter your own
2. Choose a time frame for the prediction (1 day, 1 week, 1 month, or 3 months)
3. Click "Generate Prediction"
4. View the prediction results, including:
   - Bullish or bearish prediction
   - Confidence score
   - Key factors influencing the prediction
   - Technical indicators
   - Support and resistance levels (if available)

### Batch Prediction

1. Go to the "Multiple Assets" tab
2. Select a time frame for the predictions
3. Click "Generate Batch Predictions"
4. View predictions for all predefined assets

## Technical Implementation

The Gemini Market Predictor consists of the following components:

- **`lib/gemini-service.ts`**: Service for interacting with the Gemini API
- **`components/gemini-market-predictor.tsx`**: UI component for the predictor
- **`app/dashboard/market-predictor/page.tsx`**: Dedicated page for the predictor

## Disclaimer

The predictions provided by the Gemini Market Predictor are generated by an AI model and should not be considered as financial advice. Always conduct your own research before making investment decisions.
